# 领域参考：检索、Embedding、重排与 RAG

**仅在当前系统确实涉及信息检索、向量检索、重排或检索增强生成时使用。**

## 需要识别
- 文档摄取、切分和元数据；
- query/document 编码方式；
- 向量、关键词或混合索引；
- 召回策略、Top-K、过滤条件与去重；
- reranker 的输入输出与打分方式；
- 检索上下文如何进入生成模型；
- 引用、证据归属与最终答案生成。

## 重点追踪
- 文档与查询是否共享 encoder；
- embedding 维度、归一化和相似度函数；
- 索引构建与在线检索的区别；
- 候选数量如何变化，哪些操作会过滤或重排；
- chunk ID / 文档 ID 如何映射回原文；
- 检索失败如何影响最终答案；
- 离线召回指标与端到端生成指标的区别。

不要把所有 RAG 都假定为“向量数据库 + LLM”；以当前系统实际使用的组件为准。
