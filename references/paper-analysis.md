# 通用论文阅读方法

## 阅读顺序
1. 标题、摘要、引言：研究什么问题，为什么重要？
2. 相关工作：作者认为现有方法哪里不足？
3. 方法：核心想法、模块/算法、假设和数据流。
4. 实验：数据集、对比方法、指标、消融与主要结果。
5. 局限性、结论和附录：适用范围、失败情形和实现细节。

## 输出研究卡片
| 项目 | 要记录的内容 |
|---|---|
| 研究问题 | 论文试图解决什么问题？ |
| 核心贡献 | 作者明确提出了什么新东西？ |
| 关键假设 | 方法成立依赖什么条件？ |
| 输入/输出 | 数据形式、预测对象、使用者 |
| 方法概览 | 用简短流程图表示 |
| 训练目标 | 论文描述的目标、loss 或优化策略 |
| 评估 | 数据集、指标、baseline |
| 结果 | 论文报告的具体数值及表/图位置 |
| 局限 | 作者承认或证据支持的限制 |
| 待验证 | 需要源码或实验确认的细节 |

## 论点与证据
将“作者声称”“实验支持”“你的解释”分开。不要把相关性写成因果，也不要把论文报告结果说成自己已复现的结果。

## 当源码可用
先按论文理解设计意图，再用真实实现验证模块、配置和数据路径。如果两者不一致，记录差异，不要静默补全。
